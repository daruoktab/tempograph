01 · Temporal Conversational Memory

Overwriting old facts erases context; bi-temporal edges keep the timeline intact

Standard vector RAG flattens multi-session conversations into isolated chunks, causing a chatbot to confuse outdated roles or cities with present truth. Grounded in Graphiti’s temporal model, Tempograph anchors every extracted_fact with both valid_at and invalid_at timestamps inside SurrealDB. 02 · Temporal Graph Maintenance

Three Graphiti-inspired algorithms prevent node sprawl, silent conflicts, and flat memory

Without active maintenance, multi-turn chatbots accumulate duplicate entities (“Aisha” vs. “Aisha Santoso”) and contradictory facts. Tempograph executes three targeted passes during ingestion and periodic consolidation.

1 · Dynamic Entity Deduplication

Fuzzy gating + LLM canonical merge

Computes local text similarity via rapidfuzz (token sort & partial ratio). Matches inside the ambiguous 60%–84% band trigger a contextual LLM check before merging into one SurrealDB node named after the longest, most specific variant.

2 · Bi-Temporal Invalidation

Cosine ≥ 0.35 contradiction resolution

Before inserting a fact, Tempograph compares its embedding against prior facts sharing the same entity. Pairs scoring ≥ 0.35 are classified by an LLM as duplicate, contradictory, or compatible—setting invalid_at = reference_time on superseded claims.

3 · Graph Community Detection

NetworkX Louvain macro summaries

Periodically partitions social and workplace entity subgraphs using NetworkX’s Louvain algorithm. An LLM summarizes each cluster into a community node linked via has_member edges, giving subsequent turns macro-level awareness.

03 · Unified Graph + Vector Store

One SurrealDB schema routes Agentic, Vanilla, and Hybrid queries side by side

Instead of splitting graph traversal and dense vector search across separate databases, src/surreal/schema.surql houses both the temporal fact graph and 768-dimensional session passage vectors. Switch retrieval modes below to trace which tables and graph edges each retriever queries.

Active Retrieval Pipeline

Agentic Path (RetrievalAgent)

Queries extracted_fact embeddings and traverses fact_involves to entity nodes, linking back to source episode records via has_fact and macro community summaries via has_member.

SurrealDB Schema Tables (src/surreal/schema.surql)
Table / Relation Key Fields
episode group_id, name, body, reference_time (datetime)
extracted_fact group_id, fact_text, episode_name, embedding (768-dim), entity_names, valid_at, invalid_at
entity group_id, name (canonical deduplicated identifier)
community group_id, name, summary (Louvain cluster summary)
session_passage collection, doc_id, text, embedding, metadata
Graph Edges has_fact (episode → fact), fact_involves (fact → entity), has_member (community → entity)
04 · Longitudinal Dataset Pipeline

Causal Indonesian life events turn synthetic personas into testable memory benchmarks

Inspired by LOCOMO, src/dataset/generator.py orchestrates three specialized Gemini model tiers to build dated causal event graphs (caused_by), multi-turn Bahasa Indonesia dialogues, cumulative session summaries, and conflict-resolved ground truth annotations.
